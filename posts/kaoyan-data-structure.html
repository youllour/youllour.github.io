前言 ​

本文面向 2027 年计算机考研，按照“基本概念、线性结构、树、图、查找、排序”的顺序整理数据结构核心知识点。复习时不仅要记结论，还要能画出结构变化过程、分析算法复杂度，并独立写出关键算法。

第一部分：绪论 ​

一、数据结构的基本概念 ​

1.1 基本术语 ​

  • 数据：信息的载体，是能被计算机识别、存储和加工的符号集合。
  • 数据元素：数据的基本单位，通常作为一个整体进行考虑和处理。
  • 数据项：构成数据元素的不可分割的最小单位。
  • 数据对象：具有相同性质的数据元素的集合，是数据的一个子集。
  • 数据结构：相互之间存在一种或多种特定关系的数据元素的集合。
  • 抽象数据类型（ADT）：由数据对象、数据关系和基本操作组成，与具体存储方式无关。

1.2 数据结构三要素 ​

  1. 逻辑结构：数据元素之间的逻辑关系。
  2. 存储结构：逻辑结构在计算机中的表示，也称物理结构。
  3. 数据运算：针对数据定义的操作，如插入、删除、查找和排序。

逻辑结构可分为：

逻辑结构元素关系典型结构
集合除同属一个集合外无其他关系集合、并查集
线性结构除首尾外，每个元素有唯一前驱和后继线性表、栈、队列、串
树形结构一对多树、二叉树、堆
图状结构多对多有向图、无向图

常见存储结构：

存储结构特点
顺序存储逻辑相邻的元素物理位置也相邻，可随机访问
链式存储用指针表示逻辑关系，不要求物理位置相邻
索引存储额外建立索引表，加快检索速度
散列存储根据关键字直接计算存储地址

易错点：存储结构会影响运算效率，但不改变数据的逻辑结构。

二、算法与复杂度 ​

2.1 算法的五个特性 ​

  • 有穷性：执行有限步后结束。
  • 确定性：每条指令含义明确，相同输入得到相同输出。
  • 可行性：每一步都能通过有限次基本运算完成。
  • 输入：有零个或多个输入。
  • 输出：有一个或多个输出。

一个好算法还应具备正确性、可读性、健壮性和较高的时空效率。

2.2 时间复杂度 ​

时间复杂度关注问题规模 nnn 增大时，基本操作执行次数 T(n)T(n)T(n) 的增长趋势：

T(n)=O(f(n))T(n)=O(f(n))T(n)=O(f(n))

常见数量级由小到大为：

O(1)<O(log⁡n)<O(n)<O(nlog⁡n)<O(n2)<O(n3)<O(2n)<O(n!)O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(n^3)<O(2^n)<O(n!)O(1)<O(logn)<O(n)<O(nlogn)<O(n2)<O(n3)<O(2n)<O(n!)

分析原则：

  1. 顺序语句的复杂度相加，保留最高阶。
  2. 嵌套循环的复杂度通常相乘。
  3. 条件分支取最坏路径时，应选择复杂度最大的分支。
  4. 递归算法可根据递推式或递归树分析。

如递归循环，可以假设传进去的参数为n，每执行一个递归将其参数变化，当次数为t时到临界条件，此时参数应该等于该临界条件，同时看递归调用的内部时间复杂度，将其相乘。

如while循环，可以从1~t开始列表，将每次参数的值写出，t次时的参数就是等于临界条件的

如内外for循环，分为外部循环，参数和内部循环，最后要将内部循环的次数相加得到最后的时间复杂度

2.3 空间复杂度 ​

空间复杂度主要分析算法额外使用的辅助空间。递归算法还要计算递归调用栈的空间，例如递归深度为 nnn 时，栈空间通常为 O(n)O(n)O(n)。

原地算法：辅助空间复杂度为 O(1)O(1)O(1) 的算法。

第二部分：线性表 ​

三、顺序表 ​

3.1 特点 ​

顺序表使用一组地址连续的存储单元依次存放元素。设首元素地址为 LOC(L)LOC(L)LOC(L)，每个元素占 ccc 个字节，则第 iii 个元素的地址为：

LOC(Li)=LOC(L)+(i−1)cLOC(L_i)=LOC(L)+(i-1)cLOC(Li​)=LOC(L)+(i−1)c

操作时间复杂度
按位访问O(1)O(1)O(1)
按值查找O(n)O(n)O(n)
表尾插入均摊 O(1)O(1)O(1)，最坏 O(n)O(n)O(n)
指定位置插入O(n)O(n)O(n)
指定位置删除O(n)O(n)O(n)

长度为 nnn 的顺序表在第 iii 个位置插入元素，需要移动 n−i+1n-i+1n−i+1 个元素；删除第 iii 个元素，需要移动 n−in-in−i 个元素。

3.2 优缺点 ​

优点：存储密度高，支持随机访问，缓存局部性好。

缺点：插入、删除需要移动大量元素；静态分配容量固定，动态扩容也有额外开销。

四、链表 ​

4.1 单链表 ​

单链表结点由数据域和指向后继的指针域组成：

c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

带头结点的单链表中，头结点不存放有效数据。它可以统一空表和非空表的操作，减少边界判断。

操作已知头结点已知目标结点指针
查找第 iii 个结点O(n)O(n)O(n)-
在某结点后插入-O(1)O(1)O(1)
删除某结点的后继-O(1)O(1)O(1)
删除指定结点O(n)O(n)O(n)通常可用“复制后继”在 O(1)O(1)O(1) 完成，但尾结点除外

头插法建立的链表与输入顺序相反，时间复杂度为 O(n)O(n)O(n)；尾插法配合尾指针可保持输入顺序，时间复杂度也为 O(n)O(n)O(n)。

4.2 双链表 ​

双链表结点同时保存前驱和后继指针：

c
typedef struct DNode {
    int data;
    struct DNode *prior;
    struct DNode *next;
} DNode, *DLinkList;

在结点 p 后插入结点 s 时，四条指针语句的逻辑关系为：

c
s->next = p->next;
s->prior = p;
p->next->prior = s;
p->next = s;

易错点：应先保存原有链，再修改 p->next，否则可能丢失后继结点。

4.3 循环链表 ​

  • 循环单链表的尾结点指向头结点，判空条件可写为 head->next == head。
  • 循环双链表中，头结点的 prior 指向尾结点，尾结点的 next 指向头结点。
  • 仅设置尾指针时，可以在 O(1)O(1)O(1) 时间内访问首结点和尾结点，适合频繁操作表头、表尾的场景。

4.4 静态链表 ​

静态链表用数组下标模拟指针，结点由数据域和游标域组成。它适用于不支持指针的环境，但容量固定，仍不支持随机访问。

五、线性表典型问题 ​

5.1 单链表逆置 ​

c
LNode *reverse(LNode *head) {
    LNode *prev = NULL;
    LNode *cur = head;
    while (cur != NULL) {
        LNode *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

时间复杂度为 O(n)O(n)O(n)，空间复杂度为 O(1)O(1)O(1)。

5.2 快慢指针 ​

  • 寻找中间结点：慢指针每次走一步，快指针每次走两步。
  • 判断是否有环：若存在环，快慢指针最终一定相遇。
  • 寻找倒数第 kkk 个结点：先让快指针走 kkk 步，再让快慢指针同步前进。

第三部分：栈、队列和数组 ​

六、栈 ​

栈是只允许在一端进行插入和删除的线性表，遵循 后进先出（LIFO） 原则。允许操作的一端称为栈顶，另一端称为栈底。

6.1 顺序栈 ​

若 top 指向当前栈顶元素，则：

  • 初始状态：top = -1
  • 栈空：top == -1
  • 栈满：top == MaxSize - 1
  • 进栈：先执行 ++top，再写入元素
  • 出栈：先读取元素，再执行 top--

共享栈让两个栈从数组两端向中间增长，栈满条件为：

top1+1=top2top_1+1=top_2top1​+1=top2​

6.2 栈的应用 ​

  • 括号匹配
  • 表达式求值与中缀、后缀表达式转换
  • 函数调用和递归
  • 深度优先搜索

后缀表达式求值：从左到右扫描，遇到操作数入栈；遇到运算符时弹出两个操作数，先弹出的是右操作数，计算后将结果入栈。

七、队列 ​

队列只允许在队尾插入、队头删除，遵循 先进先出（FIFO） 原则。

7.1 循环队列 ​

设数组容量为 MaxSize，front 指向队头元素，rear 指向队尾元素的下一个位置。牺牲一个存储单元以区分队空和队满：

队空：front=rear\text{队空：}front=rear队空：front=rear

队满：(rear+1) mod MaxSize=front\text{队满：}(rear+1)\bmod MaxSize=front队满：(rear+1)modMaxSize=front

队列长度：(rear−front+MaxSize) mod MaxSize\text{队列长度：}(rear-front+MaxSize)\bmod MaxSize队列长度：(rear−front+MaxSize)modMaxSize

7.2 链队列 ​

链队列通常设置队头指针和队尾指针。带头结点时，队空条件为 front == rear；入队在队尾插入，出队删除队头后的第一个结点。

7.3 双端队列 ​

双端队列允许在两端插入和删除：

  • 输入受限双端队列：只能在一端插入，两端均可删除。
  • 输出受限双端队列：两端均可插入，只能在一端删除。

八、串、数组与特殊矩阵 ​

8.1 串的模式匹配 ​

朴素模式匹配最坏时间复杂度为 O(nm)O(nm)O(nm)，其中主串长度为 nnn，模式串长度为 mmm。

KMP 算法利用已经匹配的信息避免主串指针回退，时间复杂度为：

O(n+m)O(n+m)O(n+m)

next 数组记录模式串失配后应跳转的位置，其本质是模式串前缀与后缀的最长公共匹配关系。不同教材对 next 数组下标和初值的定义可能不同，做题时应以题目给出的约定为准。

对称矩阵只需存储上三角或下三角部分，共需：

n(n+1)2\frac{n(n+1)}{2}2n(n+1)​

第四部分：树与二叉树 ​

九、树的基本概念 ​

  • 结点的度：结点拥有的子树数。
  • 树的度：树中所有结点度数的最大值。
  • 叶结点：度为 000 的结点。
  • 结点的深度：从根到该结点路径上的边数；部分教材从 111 开始计层数。
  • 结点的高度：从该结点到最远叶结点路径上的边数。
  • 树的高度：根结点的高度。

一棵有 nnn 个结点的树有 n−1n-1n−1 条边。设度为 iii 的结点数为 nin_ini​，则：

n=∑inin=\sum_i n_in=i∑​ni​

n−1=∑ii⋅nin-1=\sum_i i\cdot n_in−1=i∑​i⋅ni​

由两式可推导各类树中叶结点与分支结点的数量关系。

十、二叉树 ​

10.1 重要性质 ​

  1. 第 iii 层至多有 2i−12^{i-1}2i−1 个结点（根为第 111 层）。
  2. 高度为 hhh 的二叉树至多有 2h−12^h-12h−1 个结点。
  3. 对任意非空二叉树，若叶结点数为 n0n_0n0​，度为 222 的结点数为 n2n_2n2​，则：

n0=n2+1n_0=n_2+1n0​=n2​+1

  • 满二叉树：高度为 hhh 且有 2h−12^h-12h−1 个结点，每层结点数都达到最大值。
  • 完全二叉树：除最后一层外均满，最后一层结点从左到右连续排列。

顺序存储适合完全二叉树。普通二叉树使用顺序存储时可能浪费大量空间。

二叉链表结点包含数据域、左孩子指针和右孩子指针。含 nnn 个结点的二叉链表共有 2n2n2n 个指针域，其中非空指针有 n−1n-1n−1 个，空指针有：

2n−(n−1)=n+12n-n-1=n+12n−(n−1)=n+1

十一、二叉树遍历 ​

11.1 遍历顺序 ​

遍历方式访问顺序典型用途

中序左、根、右二叉搜索树得到有序序列

递归遍历的时间复杂度为 O(n)O(n)O(n)；递归栈空间复杂度为 O(h)O(h)O(h)，其中 hhh 为树高。

11.2 由遍历序列构造二叉树 ​

  • 先序序列 + 中序序列可以唯一确定一棵二叉树。
  • 后序序列 + 中序序列可以唯一确定一棵二叉树。
  • 层序序列 + 中序序列可以唯一确定一棵二叉树。
  • 仅有先序和后序序列通常不能唯一确定二叉树。

关键思路：先序的首元素或后序的末元素是根，再用根在中序序列中的位置划分左右子树。

十二、线索二叉树 ​

线索二叉树利用二叉链表中的 n+1n+1n+1 个空指针保存遍历序列中的前驱和后继信息。通常增加标志位：

  • ltag == 0：lchild 指向左孩子；ltag == 1：指向遍历前驱。
  • rtag == 0：rchild 指向右孩子；rtag == 1：指向遍历后继。

中序线索二叉树便于在不使用栈和递归的情况下进行中序遍历。

十三、树、森林与二叉树的转换 ​

采用 左孩子右兄弟 表示法：

  • 二叉树的左指针指向原树中结点的第一个孩子。
  • 二叉树的右指针指向原树中结点的下一个兄弟。

十四、树的应用 ​

14.1 哈夫曼树 ​

结点的带权路径长度为从根到该结点的路径长度与权值之积。树的带权路径长度为所有叶结点带权路径长度之和：

WPL=∑i=1nwiliWPL=\sum_{i=1}^{n}w_i l_iWPL=i=1∑n​wi​li​

构造哈夫曼树时，每次从当前集合中选取权值最小的两个结点作为左右子树，合并为新树，重复直到只剩一棵树。

重要结论：

  • 哈夫曼树的 WPLWPLWPL 最小，但形态不一定唯一。
  • 初始有 nnn 个叶结点时，共进行 n−1n-1n−1 次合并，总结点数为 2n−12n-12n−1。
  • 哈夫曼树不存在度为 111 的结点。
  • 哈夫曼编码是前缀编码，任一字符的编码都不是另一字符编码的前缀。

14.2 并查集 ​

并查集用于维护互不相交的集合，支持：

  • Find(x)：查找元素所属集合的代表。
  • Union(a, b)：合并两个集合。

使用 路径压缩 和 按秩合并 后，单次操作的均摊时间复杂度接近 O(1)O(1)O(1)，严格表示为 O(α(n))O(\alpha(n))O(α(n))。

16.1 邻接矩阵 ​

邻接矩阵使用 n×nn\times nn×n 的数组存储图：

  • 空间复杂度为 O(n2)O(n^2)O(n2)，适合稠密图。
  • 判断两顶点是否邻接的时间复杂度为 O(1)O(1)O(1)。
  • 无向图的邻接矩阵一定是对称矩阵。
  • 无向图第 iii 行非零元素数等于顶点 iii 的度。
  • 有向图第 iii 行非零元素数为出度，第 iii 列非零元素数为入度。

16.2 邻接表 ​

邻接表为每个顶点建立一条边表：

  • 无向图空间复杂度为 O(∣V∣+2∣E∣)O(|V|+2|E|)O(∣V∣+2∣E∣)。
  • 有向图空间复杂度为 O(∣V∣+∣E∣)O(|V|+|E|)O(∣V∣+∣E∣)。
  • 适合稀疏图。
  • 有向图邻接表便于求出度，逆邻接表便于求入度。

同一个图的邻接矩阵唯一，但邻接表会因边结点的排列顺序不同而不唯一。

17.1 广度优先搜索（BFS） ​

BFS 使用队列，从起点开始逐层访问顶点。它可以求 无权图的单源最短路径。

17.2 深度优先搜索（DFS） ​

DFS 使用递归或显式栈，沿一条路径尽可能深入，再回溯访问其他分支。

十八、最小生成树 ​

最小生成树（MST）是连通带权无向图中边权和最小的生成树。若图中各边权值互不相同，则最小生成树唯一；反之不一定唯一。

18.1 Prim 算法 ​

从一个顶点集合开始，每次选择连接已选集合与未选集合的最小权边。

  • 邻接矩阵实现：O(∣V∣2)O(|V|^2)O(∣V∣2)，适合稠密图。
  • 使用优先队列和邻接表：O(∣E∣log⁡∣V∣)O(|E|\log |V|)O(∣E∣log∣V∣)。

第六部分：查找 ​

二十一、顺序查找与折半查找 ​

21.1 顺序查找 ​

顺序查找适用于顺序表和链表，对数据是否有序没有要求，时间复杂度为 O(n)O(n)O(n)。

21.2 折半查找 ​

折半查找要求线性表 有序且支持随机访问，因此适用于顺序表，不适用于链表。

c
int binarySearch(int a[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (a[mid] == key)
            return mid;
        if (a[mid] < key)
            low = mid + 1;
        else
            high = mid - 1;
    }
    return -1;
}

折半查找判定树是一棵平衡二叉树，查找长度不超过：

⌊log⁡2n⌋+1\lfloor\log_2 n\rfloor+1⌊log2​n⌋+1

时间复杂度为 O(log⁡n)O(\log n)O(logn)。

二十二、二叉搜索树 ​

二叉搜索树（BST）满足：

  • 左子树所有关键字小于根结点关键字。
  • 右子树所有关键字大于根结点关键字。
  • 左右子树也分别是二叉搜索树。

中序遍历二叉搜索树可得到递增序列。查找、插入和删除的时间复杂度均为 O(h)O(h)O(h)：平均为 O(log⁡n)O(\log n)O(logn)，最坏退化为单链表时为 O(n)O(n)O(n)。

删除结点分三种情况：

  1. 叶结点：直接删除。
  2. 只有一棵子树：用子树替代该结点。
  3. 有两棵子树：用中序前驱或中序后继替代，再删除对应结点。

二十三、平衡二叉树 ​

AVL 树中任意结点左右子树高度差的绝对值不超过 111。平衡因子定义为：

BF=左子树高度−右子树高度BF=\text{左子树高度}-\text{右子树高度}BF=左子树高度−右子树高度

平衡结点的平衡因子只能是 −1-1−1、000 或 111。

失衡类型失衡原因调整方式
LL在左孩子的左子树插入右单旋

RL在右孩子的左子树插入先右旋，再左旋

AVL 树的查找、插入和删除时间复杂度均为 O(log⁡n)O(\log n)O(logn)。

二十四、红黑树 ​

红黑树是一种近似平衡的二叉搜索树，满足：

  1. 每个结点为红色或黑色。
  2. 根结点为黑色。
  3. 叶结点（空结点）为黑色。
  4. 红结点的孩子必须为黑色，不能出现连续红结点。
  5. 从任一结点到其所有叶结点的路径包含相同数量的黑结点。

红黑树最长路径不超过最短路径的两倍，查找、插入和删除均为 O(log⁡n)O(\log n)O(logn)。与 AVL 树相比，红黑树平衡要求较宽松，更新时旋转次数通常更少。

二十五、B 树与 B+ 树 ​

25.1 B 树 ​

一棵 mmm 阶 B 树满足：

  • 每个结点至多有 mmm 棵子树，即至多有 m−1m-1m−1 个关键字。
  • 除根结点外，非叶结点至少有 ⌈m/2⌉\lceil m/2\rceil⌈m/2⌉ 棵子树。
  • 非叶根结点至少有两棵子树。
  • 所有叶结点位于同一层。
  • 含 kkk 棵子树的结点有 k−1k-1k−1 个关键字。

B 树的插入可能引起结点分裂，删除可能引起兄弟借关键字或结点合并。

25.2 B+ 树 ​

与 B 树相比：

  • 所有记录都存放在叶结点中。
  • 非叶结点中的关键字仅起索引作用。
  • 叶结点按关键字有序链接，适合范围查询。
  • 查找无论成功与否都必须到达叶结点。

B 树和 B+ 树都通过降低树高来减少磁盘 I/O，常用于数据库和文件系统索引。

  • 除留余数法
  • 数字分析法

第七部分：排序 ​

二十七、排序的基本概念 ​

  • 内部排序：待排序记录全部放在内存中。
  • 外部排序：数据量过大，需要在排序过程中进行内外存交换。
  • 稳定性：关键字相等的记录排序后相对次序不变，则算法稳定。

稳定性是算法本身的性质，与某一次输入中是否存在相等元素无关。

二十八、插入排序 ​

28.1 直接插入排序 ​

每次将一个待排序元素插入前面已经有序的序列。

  • 最好时间复杂度：O(n)O(n)O(n)
  • 平均、最坏时间复杂度：O(n2)O(n^2)O(n2)
  • 空间复杂度：O(1)O(1)O(1)
  • 稳定

直接插入排序适合基本有序且数据量较小的序列。

28.2 折半插入排序 ​

使用折半查找确定插入位置，比较次数降为 O(nlog⁡n)O(n\log n)O(nlogn)，但移动元素次数仍为 O(n2)O(n^2)O(n2)，所以总体时间复杂度仍为 O(n2)O(n^2)O(n2)。

28.3 希尔排序 ​

希尔排序按照逐渐缩小的增量对子序列进行直接插入排序。它是不稳定排序，复杂度与增量序列有关，通常空间复杂度为 O(1)O(1)O(1)。

二十九、交换排序 ​

29.1 冒泡排序 ​

每趟通过相邻元素交换，将当前最大或最小元素移动到最终位置。

  • 最好时间复杂度：O(n)O(n)O(n)（设置交换标志）
  • 平均、最坏时间复杂度：O(n2)O(n^2)O(n2)
  • 空间复杂度：O(1)O(1)O(1)
  • 稳定

29.2 快速排序 ​

快速排序选择枢轴，将序列划分为小于枢轴和大于枢轴的两部分，再递归处理。

  • 平均时间复杂度：O(nlog⁡n)O(n\log n)O(nlogn)
  • 最坏时间复杂度：O(n2)O(n^2)O(n2)
  • 平均递归空间：O(log⁡n)O(\log n)O(logn)
  • 最坏递归空间：O(n)O(n)O(n)
  • 不稳定

当输入基本有序且总选择首元素为枢轴时，容易退化。随机选取枢轴或采用三数取中法可降低退化概率。

每完成一趟划分，枢轴元素一定到达最终位置，但其他元素不一定有序。

三十、选择排序 ​

30.1 简单选择排序 ​

每趟从未排序部分选择最小元素，放到其最终位置。

  • 最好、平均、最坏时间复杂度均为 O(n2)O(n^2)O(n2)
  • 空间复杂度为 O(1)O(1)O(1)
  • 不稳定

简单选择排序的元素交换次数不超过 n−1n-1n−1 次。

30.2 堆排序 ​

大根堆满足每个结点的值均不小于其孩子；小根堆则相反。建立大根堆后，反复将堆顶与末尾元素交换，再调整剩余元素，可得到递增序列。

  • 建堆时间复杂度：O(n)O(n)O(n)
  • 排序时间复杂度：O(nlog⁡n)O(n\log n)O(nlogn)
  • 空间复杂度：O(1)O(1)O(1)
  • 不稳定

完全二叉树从 000 开始编号时，结点 iii 的孩子下标为 2i+12i+12i+1 和 2i+22i+22i+2，最后一个非叶结点下标为：

⌊n2⌋−1\left\lfloor\frac{n}{2}\right\rfloor-1⌊2n​⌋−1

三十一、归并排序 ​

归并排序将序列划分为若干有序子序列，再逐层合并。

  • 最好、平均、最坏时间复杂度均为 O(nlog⁡n)O(n\log n)O(nlogn)
  • 空间复杂度为 O(n)O(n)O(n)
  • 稳定

归并排序适合顺序存储，也适合链式存储；二路归并还常用于外部排序生成归并段。

三十二、基数排序 ​

基数排序按关键字的各位进行多趟分配和收集。设记录数为 nnn，关键字有 ddd 位，每位有 rrr 种取值，则：

T(n)=O(d(n+r))T(n)=O(d(n+r))T(n)=O(d(n+r))

空间复杂度为 O(n+r)O(n+r)O(n+r)。基数排序不是基于比较的排序，通常是稳定的。

三十四、外部排序 ​

外部排序通常采用多路归并：

  1. 将文件分块读入内存，对每块进行内部排序，生成初始归并段。
  2. 对归并段进行多趟归并，直到形成一个有序文件。

减少外存读写次数的方法：

  • 增大归并路数 kkk，减少归并趟数。
  • 使用置换选择排序生成更长的初始归并段。
  • 使用最佳归并树，使总读写代价最小。
  • 使用败者树降低多路归并中选择最小元素的比较次数。

若有 rrr 个初始归并段，进行 kkk 路归并，则归并趟数为：

⌈log⁡kr⌉\lceil\log_k r\rceil⌈logk​r⌉

三十五、高频结论 ​

  1. 顺序表支持随机访问，链表不支持随机访问。
  2. 栈和队列的逻辑结构都属于线性结构，区别在于运算受限的位置不同。
  3. 非空二叉树始终满足 n0=n2+1n_0=n_2+1n0​=n2​+1。
  4. 二叉链表有 n+1n+1n+1 个空指针域。
  5. 完全二叉树适合顺序存储，普通二叉树更适合链式存储。
  6. BFS 使用队列，DFS 使用栈或递归。
  7. 最小生成树只适用于连通带权无向图；Dijkstra 不能处理负权边。
  8. 折半查找要求有序和随机访问两个条件同时满足。
  9. AVL 树严格平衡，红黑树近似平衡，B/B+ 树适合外存索引。
  10. 散列查找效率主要取决于装填因子、散列函数和冲突处理方法。
  11. 堆排序建堆为 O(n)O(n)O(n)，完整排序为 O(nlog⁡n)O(n\log n)O(nlogn)。
  12. 快速排序每趟确定一个枢轴的最终位置，冒泡排序每趟确定一个最大或最小元素的最终位置。

三十六、复习建议 ​

  • 第一轮：理解定义和结构，能够手动画出链表、树、图的变化过程。
  • 第二轮：按章节整理性质、公式和复杂度，独立完成基础算法。
  • 强化阶段：集中训练遍历序列、AVL 调整、图算法、散列 ASL 和排序过程。
  • 冲刺阶段：回顾错题和易混结论，限时完成算法题并检查边界条件。

算法题书写时应明确：输入与输出、数据结构定义、核心循环或递归、终止条件、边界情况以及时空复杂度。只背代码而不理解不变量，很容易在题目稍作变化时失分。
